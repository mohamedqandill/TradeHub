# TradeHub

**TradeHub** is a modern multi-vendor marketplace mobile application built using **Flutter**.
It enables users to discover products, explore brands, and shop from multiple stores in a seamless and scalable platform.

The project focuses on **performance, clean architecture, and a smooth shopping experience**.

---

# Features

## Multi-Vendor Marketplace

TradeHub supports multiple sellers where each store can manage and showcase its own products while customers can browse everything in one unified marketplace.

## Advanced Product Browsing

Users can easily explore products with organized categories, product details, and brand information to enhance discovery.

## Product Details Experience

Each product includes a complete detail page containing:

* Product images
* Detailed description
* Reviews
* Brand story
* Store information
* Overall rating

This gives users full context before making a purchase decision.

## Smart Cart System

Users can add items to the cart and manage their shopping flow easily with a smooth and responsive interface.

## Reviews & Ratings

Customers can view ratings and reviews for products to help them evaluate product quality before buying.

## Brand Story Section

Each brand can showcase its identity and background to build trust with customers.

## Store Information

Users can access detailed store information including:

* Store location
* Contact phone
* Email address

This allows direct communication between buyers and sellers.

## Dark Mode Support

TradeHub includes a complete dark mode theme to provide a comfortable user experience in different lighting conditions.

## Localization

The app supports **Arabic and English languages**, enabling a wider audience to use the platform.

# Tech Stack

TradeHub is built using modern mobile development technologies.

* **Flutter** for cross-platform mobile development
* **Dart** as the core programming language
* **easy_localization** for multilingual support
* **flutter_screenutil** for responsive UI across devices

The project structure focuses on maintainability and scalability.
